# VIKI Agent — Bots and Kanban

About 1 minute 33 seconds, narrated by a generated voice, with optional English captions.

VIKI Agent brings Claude Code, your project knowledge, and a team of Bots into one local workspace. Turn context into reviewed work.

Start with the Vault. Your goals, tasks, sources, and decisions stay in Markdown you own. Bring the knowledge that matters into each conversation.

Decision considers project signals, timing, and your feedback. It can stay quiet, suggest a next step, or start eligible work within the grants and limits you set.

Meet your Bots. Chief routes requests. Ops runs standups. Research finds sources. Writer drafts. Engineer plans code changes. Desk handles one-off jobs. Checker reviews the evidence.

Give Chief the outcome. Kanban shows each task's status, Bot owner, and Done-when checklist. Open the specialists' work, then inspect Checker's review.

Review permission requests. Follow the conversation. Inspect the file and the changes. Read the result and its checks.

VIKI Agent. Proactive coding. Decisions you control.

The screens use an example project and scripted replies, and diagrams explain the workflow.

Proactive work requires Proactive VIKI to be enabled and unpaused, an open app window,
and the relevant grants and activity limits. Claude Code's permission prompts and configured
hooks apply to its actions. This example has the optional Kanban skill configured for Chief.
The Kanban view shows task status and ownership; opening a card does not start a Bot.
The specialist chats are opened explicitly. Engineer prepares plans and briefs for a regular
coding chat.
