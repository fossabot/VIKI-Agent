About the demonstration

The app screens use an example project with scripted replies. Diagrams explain the workflow, and the narration is generated. Proactive work requires Proactive VIKI to be on and not paused, an open app window, and the relevant grants and activity limits. Claude Code's permission prompts and configured hooks apply to its actions. The Kanban example has its optional skill configured; the user opens the specialist chats explicitly.
