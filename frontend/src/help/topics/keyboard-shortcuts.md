# Keyboard shortcuts

All of VIKI Agent's keyboard shortcuts, with notes on dialogs, IME typing and macOS keys.

## Dialogs, IME and macOS

Shortcuts do nothing while a dialog is open, or while an IME is composing text — except
`Alt`+`V` and `Alt`+`T`, which also work while VIKI's panel is open. On macOS, ⌘ replaces
`Ctrl` and ⌥ replaces `Alt` on this page, unless a row says otherwise.

## All shortcuts

| Shortcut | What it does |
|---|---|
| `Ctrl`+`K` | Open the search palette |
| `Ctrl`+`F` | Find, select and export in the open chat |
| `Alt`+`N` or `Ctrl`+`Shift`+`O` | Start a new session |
| `Ctrl`+`,` | Open Settings |
| `Ctrl`+`\` | Split the tab to the right |
| `Ctrl`+`1`–`4` | Focus that pane |
| `Alt`+`W` | Close the tab |
| `Alt`+`1`–`8` | Jump to that numbered tab in the focused pane |
| `Alt`+`9` | Jump to the last tab in the focused pane |
| `Alt`+`V` | Open or close VIKI's panel |
| `Alt`+`T` | Start or end a voice conversation with VIKI, opening its panel |
| `Esc` | Go back a level, or stop a running reply |
| `?` | Open this page |
| `Enter` | Send your message |
| `Shift`+`Enter` | Add a line without sending |
| `↑` | Recall your last message, in an empty message box |
| `↑` `↓` `Enter` `Esc` | Move, pick or close, in the slash menu and the search palette |
| `Ctrl`+`Shift`+`Left`/`Right` | Reorder the focused tab — the same on every platform |
