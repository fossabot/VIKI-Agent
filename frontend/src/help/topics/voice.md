# Voice

Speak to VIKI instead of typing, hear replies read aloud, or hold a full hands-free voice conversation.

## Dictation

Press the microphone to dictate. It puts your recognized words into the message box for you to review. It never sends them on its own.

Dictation needs a local speech model. In **Settings** › **Chat**, check **Dictation language**, **Dictation model** and **Dictation runs on** to see or change what VIKI uses.

## Read aloud

Select **Read aloud** under a finished reply to hear it. Choose its voice through **Read replies aloud with**, in **Settings** › **Chat**:

| Read replies aloud with | What it does |
|---|---|
| **System voices** | Uses the voices already installed on this computer. |
| **Natural voices** | A voice pack VIKI installs for you, on Windows with an NVIDIA graphics card. Select **Install natural voices** to add it. |
| **My own Voicebox app (advanced)** | A separate program you install and run yourself. |

Once installed, pick a **Natural voice** for each language, and select **Preview** to hear it first.

While a reply is read aloud, an **AI voice** label shows beside its controls; a hands-free conversation shows it in its strip.

## Hands-free conversation

Select the round **Hands-free** button, shown in an empty message box, to start one. Its tip reads **Start voice conversation**. Press `Esc` anytime to end the conversation. It also works in VIKI's chat, in its panel, where `Alt`+`T` starts or ends it; one voice conversation runs at a time.

Open its **Voice options** chevron to switch voices. Turn on **Speak while VIKI writes** so VIKI starts speaking before it finishes a reply.

## Good to know

If a reply is not read aloud, a note beside that reply's own **Read aloud** button explains why. Below 800 pixels wide, the window hides the **Voice options** chevron to save space.

A natural voice starts the first time you use it, then stops again after 5 minutes unused.
