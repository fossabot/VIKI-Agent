# What VIKI read

Every finished reply in a vault chat shows where VIKI's answer came from.

## The chips
A chip is a vault note VIKI read, a folder it searched, or a page it fetched, shown under the
reply in the order VIKI read them. Beyond the first few, a more toggle reveals the rest;
**Show fewer** collapses them again. A reply that read no note from your vault shows a
**No vault sources** badge beside any search or web chips — that only means no note was read,
not everything VIKI drew on to write the reply.

## Click and hover
Hover or focus a note chip to see its exact reference, its Summary section (or
**No summary section.** when it has none), and its modified date and confidence when the note
sets them. Click a chip to open what it points to: the note, the searched folder, or the
fetched page.

## Reads by VIKI's agents
When VIKI sends part of the work to one of its own agents, that agent's reads are counted too,
each one labelled with the agent's name — so the chips cover what the whole team read, not
only VIKI's own reads.

## Save or revisit what VIKI read
**Save as note** turns a reply into a new vault note. In an ordinary vault it opens a
prefilled editor for you to review before **Create note**; in a protected vault it opens a chat
draft asking VIKI to save it instead — nothing is written until you confirm. In the right panel,
**Files in this chat** lists every file VIKI changed or read, every page it fetched and every
search it ran this chat, newest first, with anything only an agent touched filed under
**By agents**.
