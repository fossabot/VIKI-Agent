# Welcome

This folder is your vault. Your notes are plain Markdown files; VIKI reads them
and, with your permission, Claude Code edits them from here.

## Getting started

- Write notes as `.md` files anywhere in this folder.
- Create folders that suit your work. VIKI imposes no layout.
- `CLAUDE.md` in this folder, if you add one, is the instruction file Claude Code reads.

## What the app does here

VIKI Agent created this folder, this note and, if you asked for it, `.viki/vault.json`.
When you accepted the suggested location, it also created the folders above this one
(`VIKI` in your home folder and `Vaults` inside it); cancelling a setup removes only the
files it wrote, never those folders.
It changes nothing else on its own: every other change to these files is made by Claude Code
in a session you start, under the permissions you grant each time.

You can delete this note at any time.
